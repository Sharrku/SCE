# SCE - Sharrku Cinematic Encounter

Cinematic boss encounters for Foundry VTT (v13/v14, any system; HP path defaults to D&D 5e).

- Cinematic intro: the scene dims, narration lines appear one by one, then the boss artwork, then the title
- Atmospheres: embers, smoke, lightning storm, frost, radiance, abyss
- Shared boss health bar with phase markers
- Phases at HP thresholds (line, sound, screen shake)
- Seven defeat effects and a victory screen
- Starts combat and music automatically
- Open with **Alt+E** or the dragon button in the token controls (GM only)

## Installation

In Foundry: *Add-on Modules -> Install Module -> Manifest URL*:

```
https://github.com/Sharrku/SCE/releases/latest/download/module.json
```

All files in `sounds/` are synthesized for this module and may be used freely.
